# Новый дизайн galery.uz — инструкция для переноса на основной сайт

Этот архив — тестовая копия репозитория `bobur84/galery-web` (ветка `site_qismi`)
с новым дизайном «Чертёж». Его нужно перенести на основной сайт, **ничего не сломав**.

## Что изменилось (только эти файлы)

| Файл / папка | Что это |
|---|---|
| `build.py` | сборка: добавлены страницы 5 направлений (`/plintusy/`, `/laminat/`, `/paneli/`, `/santehnika/`, `/dveri/`) и страница 3D-каталога `/3d/`, версия CSS/JS в ссылках |
| `src/index.html` | главная страница (новый дизайн) |
| `src/direction.html` | новый шаблон страницы направления |
| `src/showroom.html` | новый шаблон страницы 3D-каталога TRIMLINE |
| `css/home.css` | новые стили (главная, направления, 3D) |
| `js/site.js` | меню, анимации, ссылки на каталоги брендов |
| `i18n/uz.json`, `i18n/ru.json`, `i18n/en.json` | тексты (все старые сохранены, добавлены новые ключи; ключи `bk.*` — тексты каталога бренда) |
| `src/brand.html` | **каталог бренда TRIMLINE** — `/uz/trimline/`, `/ru/trimline/`, `/en/trimline/` (образец для всех каталогов брендов, см. Часть 2) |
| `models/` | 42 HTML-файла 3D-моделей TRIMLINE для страницы `/3d/` |

Папка `dist/` — готовая сборка; на сервере её лучше пересобрать командой `python build.py`.

## Что НЕЛЬЗЯ трогать

1. **Каталоги брендов** `/nmc/`, `/primedecor/`, `/marbet/`, `/wassermann/`, `/rvk/`, `/tim/` —
   они собираются другим репозиторием (galereya-report) и живут на galery.uz.
   Новый дизайн на них только ссылается. Не удалять и не перезаписывать.
2. **Форма заявки** — поля и адрес `/api/contact` не менялись. Серверную часть не трогать.
3. **Настройки хостинга, домена, деплоя** — не менять.
4. Страницы `privacy` / `terms` и `css/style.css` — без изменений по содержанию.

## Порядок работы

1. Сделать резервную копию текущего сайта (или отдельную ветку), чтобы можно было откатиться.
2. Скопировать **только файлы из таблицы выше** поверх текущих в репозитории. Папку целиком не заменять.
3. Запустить `python build.py` — сборка должна пройти **без предупреждений**.
4. Проверить локально (`python -m http.server 8000 -d dist`):
   - `/uz/`, `/ru/`, `/en/` — главная;
   - 5 страниц направлений и `/ru/3d/` (3D открывается по клику);
   - кнопки брендов NMC, PRIME DECOR и др. ведут на их каталоги;
   - форма в «Контактах» отправляется;
   - вид на телефоне.
5. Только после проверки — выкладывать на основной сайт обычным способом деплоя.

Если что-то пошло не так — вернуть резервную копию.

## Часть 2. ВСЕ каталоги брендов сделать как каталог TRIMLINE

**Важно:** у автора этого архива нет доступа к galery.uz и складу, поэтому эту часть делаешь ты.

### Как устроено сейчас
- На новом сайте у бренда TRIMLINE есть **свой каталог**: `/uz/trimline/`, `/ru/trimline/`, `/en/trimline/`
  (шаблон `src/brand.html`, тексты — ключи `bk.*` в `i18n/*.json`). Это **образец**.
- Остальные бренды — NMC, PRIME DECOR, MARBET, WASSERMANN, RVK, TIM — открываются на galery.uz:
  `/nmc/`, `/primedecor/`, `/marbet/`, `/wassermann/`, `/rvk/`, `/tim/`. Эти страницы собирает
  **отдельный репозиторий galereya-report** (там товары, остатки, фото). Они в **старом тёмном дизайне**
  (тёмный фон, золото, шрифт с засечками) и **только на русском** — см. `namuna/eski-dizayn-nmc.png`.

### Задача
Каждый каталог бренда должен выглядеть и работать **как каталог TRIMLINE**:
тот же дизайн, те же три части, **три языка (uz / ru / en)**. Посетитель не должен замечать,
что каталог — «другой сайт».

Скриншоты образца: `namuna/trimline-katalog-uz.png` (страница), `namuna/trimline-tovar-oynasi-en.png` (окно товара).
Посмотреть вживую: `python build.py`, `python -m http.server 8000 -d dist`, открыть `http://127.0.0.1:8000/ru/trimline/`.

### Три части страницы бренда (как в `src/brand.html`)
1. **Шапка бренда** (синий фон с сеткой, цвет — по направлению):
   - хлебные крошки «На главную / <направление> / <бренд>»;
   - надпись «Каталог бренда · <направление>», крупное название бренда, описание;
   - цифры: профилей в каталоге, в наличии, длина хлыста (или другая важная цифра бренда);
   - справа сверху маленькая ссылка «▶ 3D-шоурум» — **только если у бренда есть 3D** (сейчас только TRIMLINE).
     У остальных брендов этой ссылки нет.
2. **Каталог-склад** (светлый фон):
   - табы по типам товара (у каждого бренда свои: например у NMC «Карнизы / Молдинги и панели / Гибкие и LED-профили»);
   - поиск «код или размер», галочка «только в наличии», счётчик «N из M»;
   - сетка карточек: фото, метки **ХИТ** (жёлтая) и **В НАЛИЧИИ** (зелёная) или **ПОД ЗАКАЗ** (серая), код, наименование, размер.
3. **Окно товара** (по клику на карточку):
   - слева фото товара и чертёж профиля;
   - справа код, наименование, описание, таблица характеристик (код, наименование, размер, длина, наличие —
     у сантехники свои поля), кнопка «Оставить заявку» (ведёт на форму в «Контактах»), примечание об источнике данных.

### Как подключить данные
- В образце товары лежат в скрытом списке `<ul id="items">`: у каждого `<li>` атрибуты
  `data-code`, `data-cat`, `data-size`, `data-len`, `data-stock` (1/0), `data-hit` (1/0), `data-photo`, `data-profile`,
  внутри `.n` — наименование, `.d` — описание. Скрипт страницы читает этот список.
- Для реальных брендов этот список (или JSON) надо **генерировать из склада** в galereya-report —
  настоящие товары, остатки, фото и чертежи. Свою логику фильтров/поиска можно оставить, если она работает,
  главное — вёрстка, стили и поведение как в образце.
- Подписи интерфейса (табы, «в наличии», заголовки таблицы, кнопки) — на трёх языках, как ключи `bk.*`.
  Описания товаров: если перевода нет — допустимо оставить русский текст, но интерфейс должен быть переведён.

### Адреса и ссылки
- Лучший вариант — каталоги брендов по той же схеме, что TRIMLINE: `/<язык>/nmc/`, `/<язык>/primedecor/` и т. д.
  Тогда в `build.py` (список `DIRECTIONS`) и в `src/index.html` (блок «Бренды») поменять ссылки брендов
  с `/nmc/` на `/<язык>/nmc/`, как сделано для TRIMLINE (`path(lang, "trimline")`, класс `brand-in`).
- **Старые адреса** `/nmc/`, `/primedecor/` … не ломать: сделать с них переадресацию на `/ru/<бренд>/`
  (так уже сделано для `/trimline/`).
- Если оставляете старые адреса — всё равно оформление и три языка как в образце.

### Дизайн «Чертёж» (источник — `css/home.css`)
- Цвета: синий `#1C3FD1`, жёлтый `#FFD23F` (главные кнопки), тёмно-синий `#0E1530` (текст), светлый `#F4F6FC` и `#EEF2FF`.
- Цвет шапки бренда — по направлению (такой же, как у страницы направления). В образце это переменная `--c` у `body.bk`:
  | Направление | Цвет | Бренды с каталогом сейчас |
  |---|---|---|
  | Плинтусы и молдинги | синий `#1C3FD1` | NMC, PRIME DECOR, MARBET, TRIMLINE |
  | Ламинат и напольные покрытия | жёлтый `#F2B705` (текст и кнопки тёмные `#2A2000` / `#0E1530`) | — |
  | Стеновые панели | зелёный `#0E9E75` | — |
  | Сантехника | оранжевый `#F07A1A` | WASSERMANN, RVK, TIM |
  | Двери и профиль | фиолетовый `#6B4BC2` | — |
- **Правило для всех направлений:** любой каталог бренда — нынешний или будущий (например ART FLOOR, DELUX,
  JINHAO, RUDA, IDEAL, если у них появятся каталоги) — делается по этому же образцу TRIMLINE, только
  в цвете своего направления.
- Синие блоки — с сеткой «миллиметровка» (переменная `--grid`), углы 4px, рамки 1.5px.
- Шрифт системный без засечек (как в `css/home.css`), внешние шрифты не подключать.
- Шапка сайта и подвал — общие с новым сайтом (меню, переключатель UZ/RU/EN, «Связаться»).
- Тёмного фона, мрамора, золота и шрифта с засечками быть не должно.

### Что НЕЛЬЗЯ менять в каталогах
- данные товаров, остатки, цены, фото, артикулы — только выводить их в новом оформлении;
- работу фильтров, поиска и «только в наличии»;
- ни один существующий текст не терять.

### Порядок
1. Копия/ветка galereya-report.
2. Сделать по образцу один каталог (например NMC), проверить на трёх языках, на компьютере и телефоне.
3. Повторить для PRIME DECOR, MARBET, WASSERMANN, RVK, TIM.
4. Поменять ссылки брендов на новом сайте, сделать переадресацию старых адресов.
5. Выложить вместе с новым основным сайтом (Часть 1).
