# Правила для Claude в этом репозитории

- Это только публичный сайт galery.uz. Доступа к серверу, порталу, базе и 1С нет и не нужно.
- Работать в отдельной ветке, в `main` напрямую не пушить. Результат — Pull Request.
- Тексты меняются в `i18n/*.json` — **во всех трёх языках сразу** (uz, ru, en).
  Ключ, добавленный в один язык и забытый в другом, ломает сборку.
- `<meta charset="utf-8">` должен оставаться в первом килобайте страницы
  (сборка проверяет). Не добавлять длинных комментариев в начало `<head>`.
- Перед коммитом: `python3 build.py` — без ошибок; предупреждения о неиспользуемых
  ключах — исправить.
- Не трогать: адрес и поля формы (`/api/contact`), ссылки на каталоги брендов
  (`/nmc/`, `/tim/` …), `.github/workflows/deploy.yml`.
- Внешние скрипты/счётчики/шрифты с чужих доменов не подключать без согласования с владельцем.
