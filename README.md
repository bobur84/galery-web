# galery.uz — публичный сайт

Статический сайт на трёх языках (uz / ru / en). Только стандартная библиотека Python 3.

```
src/        шаблоны страниц (index.html — главная, legal.html — документы)
i18n/       тексты на каждом языке: uz.json, ru.json, en.json
legal/      политика конфиденциальности и условия (по файлу на язык)
css/        стили
company.json реквизиты компании (общие для всех языков)
build.py    сборка → dist/<язык>/
```

## Как посмотреть локально

```bash
python3 build.py
python3 -m http.server -d dist 8000
```
Открыть http://127.0.0.1:8000/ru/ (корень `/` на сервере сам выбирает язык — локально его нет).

## Как вносить правки

1. Ветка от `main`: `git checkout -b sayt/<что-делаем>`
2. Правки → `python3 build.py` должен пройти без ошибок.
3. `git push` → Pull Request в `main`. Проверка `check` соберёт сайт.
4. После слияния в `main` сайт сам уходит на galery.uz (workflow `deploy`, ~1 мин).

## Что НЕ здесь

- **Каталоги брендов** `/nmc/ /tim/ /rvk/ /marbet/ /primedecor/ /wassermann/` —
  собираются из базы в репозитории `galereya-report` (`web/<бренд>/`). Ссылки на них
  с главной менять можно, сами страницы — нет. Но они берут стили из **`/css/style.css`**
  этого репозитория — меняя общие классы, проверьте и каталоги (например, galery.uz/tim/).
- **Форма заявки** шлёт POST на `/api/contact` — это портал (galereya-report).
  Поля формы и адрес не менять без согласования.
- **nginx, выбор языка по стране, сертификат** — `galereya-report/deploy/`.
